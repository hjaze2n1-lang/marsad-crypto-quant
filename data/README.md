# بيانات السوق في GitHub

هذا المستودع **عام**؛ كل ملف تضيفه هنا يصبح قابلًا للعرض والتنزيل من الجميع.

لكل زوج وفريم:

1. ارفع CSV إلى `data/<SYMBOL>/<TIMEFRAME>.csv`، مثل `data/BTCUSDT/1d.csv`.
2. أضف سجلًا داخل مصفوفة `datasets` في `data/catalog.json`، مثل:

   ```json
   { "symbol": "BTCUSDT", "timeframe": "1d", "file": "BTCUSDT/1d.csv" }
   ```

3. احتفظ بترتيب الشموع تصاعديًا، واستخدم أعمدة OHLCV القياسية. راجع ملف README الرئيسي للأسماء والقواعد المدعومة.

الكتالوج مطلوب لأن الاستضافة الثابتة لا تستطيع استعراض محتويات المجلد تلقائيًا. سجّل كل زوج/فريم مرة واحدة، والمسار في `file` نسبي إلى مجلد `data/`.

أين أضع الملف؟

فتح مجلد data على GitHub ↗

أنشئ مجلدًا باسم العملة، ثم ملفًا باسم الفريم:

data/
├── catalog.json
└── BTCUSDT/
    ├── 1d.csv
    └── 4h.csv

مثال المسار: data/BTCUSDT/1d.csv. كل ملف يمثل زوجًا وفريمًا واحدًا.

كيف أسجل الملف؟

data/catalog.json

أضف عنصرًا داخل مصفوفة datasets؛ المسار في file نسبي إلى مجلد data:

{
  "datasets": [
    {
      "symbol": "BTCUSDT",
      "timeframe": "1d",
      "file": "BTCUSDT/1d.csv"
    }
  ]
}

بعد رفع CSV والكتالوج إلى الفرع main، يقرأ الموقع الملف عند اختيار الزوج والفريم.

تنسيق CSV المطلوب

CSV فقط
timestamp,open,high,low,close,volume
2024-01-01T00:00:00Z,42000,43000,41500,42500,123.45
2024-01-02T00:00:00Z,42500,43200,42100,42800,98.7
الصيغة والترتيبCSV يكفي؛ لا تحتاج تحويلًا إلى JSON. استخدم ترويسة الأعمدة الموضحة، أو ملف Binance الشائع الذي يبدأ بـ open_time,open,high,low,close,volume. اكتب الوقت بصيغة ISO-8601 أو Unix بالثواني/الميلي ثانية، ورتب الشموع من الأقدم إلى الأحدث واحذف الطوابع المكررة.
قيم OHLCVالأرقام بقيمة عشرية بالنقطة، دون فواصل آلاف. يجب أن يحيط High وLow بقيمتي Open وClose، وألا يكون Volume سالبًا. أسماء الزوج والفريم تأتي من مسار الملف والكتالوج.

# مرصد — محلل كمي محلي للعملات الرقمية

واجهة عربية RTL أحادية الصفحة لقراءة ملفات OHLCV التاريخية. تعمل بلا API وبلا Backend، وتناسب استضافة GitHub Pages والتشغيل محليًا عبر Acode.

> هذه نسخة أولية للتحليل الوصفي، لا تصدر إشارات تداول ولا تعد بدقة تنبؤية. مناطق FVG وOrder Block والقمم/القيعان تُحسب بقواعد تقريبية موضحة أدناه.

## تشغيل سريع

- **Acode على Android:** انسخ المجلد كاملًا إلى الهاتف، افتح `index.html` في معاينة Acode. إذا منع WebView وحدات JavaScript أو IndexedDB عند فتح `file://`، شغّل معاينة Acode المحلية/خادمها ثم أعد فتح الصفحة عبر `http://localhost`.
- **الحاسوب:** شغّل خادم ملفات ثابت داخل المجلد، مثل `python3 -m http.server 8000` ثم افتح `http://localhost:8000`.
- **GitHub Pages:** ارفع محتويات المجلد إلى مستودع GitHub، ثم من Settings → Pages اختر فرع النشر ومجلد الجذر. لا يلزم Python أثناء الاستضافة.

لا يوجد Backend ولا طلبات بيانات سوق إلى الإنترنت. ملفات الشموع تحفظ في IndexedDB على الجهاز والمتصفح الحالي؛ حذف بيانات الموقع/المتصفح قد يمسحها. زر العينة يولّد بيانات اصطناعية بوضوح للتجربة فقط.

## استيراد السوق

CSV أو JSON. الحقول المطلوبة: `timestamp,open,high,low,close,volume`. الوقت يقبل تاريخ ISO أو Unix seconds/milliseconds. يجوز أن تحتوي بيانات CSV حقول `symbol` و`timeframe` لكن التعيين الافتراضي يتم من حقلي الاستيراد. تدعم صيغة Binance الشائعة بدون عنوان: `open_time,open,high,low,close,volume,...`.

رتّب الصفوف تصاعديًا من الأقدم إلى الأحدث قبل الاستيراد، واحذف الشموع المكررة إن وجدت. الملفات الكبيرة يفضّل CSV: يُقرأ على أجزاء ويُحفظ كل 500 شمعة، ويسترجع الشارت فقط نافذة 120/240/480 شمعة. تُحسب إحصاءات الحجم السنوية من IndexedDB بدفعات منفصلة.

لفحص ملف CSV قبل إدخاله (اختياري):

```bash
python3 tools/validate_ohlcv.py path/to/market.csv
```

## ما الذي يحسبه التطبيق؟

- **الاتجاه:** EMA 20 مقابل EMA 50 وميل EMA 20 على خمس شمعات، ويتطلب 50 إغلاقًا.
- **RSI:** الفترة 14 بطريقة Wilder؛ التشبع الشرائي ≥70 والبيعي ≤30.
- **القمم/القيعان:** Pivot يتطلب خمس شمعات على كل جانب. العلامة توضع على شمعة المحور بعد اكتمال الشموع الخمس اللاحقة؛ أي أنها متأخرة بطبيعتها وليست معرفة لحظية للقاع النهائي.
- **FVG:** عدم تداخل بين مدى الشمعة الحالية ومدى الشمعة قبل اثنتين؛ تبقى «غير مكتملة» حتى عبور السعر الحد المقابل كاملًا.
- **Order Block:** آخر شمعة معاكسة ضمن خمس شمعات قبل شمعة إزاحة جسمها ≥60% من مداها، أغلقت بعد قمة/قاع Pivot وأعلى/أدنى نطاق 12 شمعة؛ يُستبعد الصندوق بعد إغلاق لاحق يتجاوزه.
- **الحجم السنوي:** أعلى شمعة حجم منفردة لكل سنة، وتغير الإغلاق بعد 20 شمعة متاحة. لا يُخلط حجم الأصل الأساسي مع الحجم المقوم بالدولار.
- **تنصيف Bitcoin:** التاريخ التاريخي يُربط بارتفاع كتلة معروف. الحدث التالي عند 1,050,000 تقريبًا في 2028، لكن يومه غير دقيق قبل بلوغ ارتفاع الكتلة.

## المصادر والحدود

تواريخ التنصيف المعروضة تستند إلى [Bitcoin.org — Halving](https://www.bitcoin.org/en/halving). الأداء يعتمد على جودة ملفك، ترتيب الشموع، والمنطقة الزمنية (التخزين بتوقيت UTC). التحليل يعمل على نافذة الشارت الظاهرة؛ النقاط والمناطق لا تمثل استراتيجية تداول أو ضمانًا للنتيجة.
